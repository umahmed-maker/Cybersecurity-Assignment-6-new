# Assignment 6 — Phishing Detection and XSS Defense

Start with `Research_Report.md`. Copy `data/phishing.csv` from [Assignment 5](https://github.com/umahmed-maker/Cybersecurity-Assignment-5) into this package. Run `pip install -r requirements.txt` and `python experiment.py`. Read `results/model_comparison.csv` and insert the **actual** results into the report. `index.html` is a GitHub Pages-ready overview and safe XSS demonstration. **No new model performance claims have been made or verified in this package.**
